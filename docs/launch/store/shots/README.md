# The store pictures

Made by `python3 tools/store-shots.py` from the real game (do not edit by hand; run it again after the look changes).
Every picture is a JPEG with no transparency, at exactly the size its store asks for. `sheet.jpg` shows them all at once.

| Where it goes | Files | Size |
|---|---|---|
| App Store Connect → iPhone 6.9" Display | `ios-6.9-01-…` to `-08-…` | 1320 × 2868 |
| App Store Connect → iPad 13" Display | `ios-13-01-…` to `-08-…` | 2752 × 2064 |
| Play Console → Main store listing → Phone screenshots | `play-phone-01-…` to `-08-…` | 1080 × 1920 |
| Play Console → Main store listing → 10-inch tablet screenshots (7-inch takes the same) | `play-tablet-01-…` to `-08-…` | 2560 × 1600 |
| Play Console → Main store listing → Feature graphic | `play-feature-1024x500.jpg` | 1024 × 500 |

Upload them in this order (the first two or three are the ones people see in search):

1. **Sow every seed by hand** — a relay turn mid-sow, the brass count over the hand
2. **See where your seeds will land** — the path marks and capture rings after the first tap
3. **Learn it in one minute** — the first-game lesson, step 2 (a capture of 4)
4. **Play a friend on WhatsApp** — the Rooms screen with its four-letter code
5. **A new puzzle every day** — the daily puzzle's result card, solved
6. **Opponents with character** — the Game over card with the record and rating
7. **Two of you, one phone** — two of us, the board turned to Player 2
8. **Carved boards, real seeds** — the store with Benin bronze on the board
