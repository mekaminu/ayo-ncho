# The store pictures in French

Made by `python3 tools/store-shots.py --lang=fr` from the real game in French (do not edit by hand). The same eight screens as
`../shots/`, the same sizes, under the French captions of `../listing-fr.json`. `sheet.jpg` shows them all at once.

In this order, as the English:

1. **Semez chaque graine à la main** — a relay turn mid-sow, the brass count over the hand
2. **Voyez où tomberont vos graines** — the path marks and capture rings after the first tap
3. **Apprenez en une minute** — the first-game lesson, step 2 (a capture of 4)
4. **Jouez avec un ami sur WhatsApp** — the Rooms screen with its four-letter code
5. **Une nouvelle énigme chaque jour** — the daily puzzle's result card, solved
6. **Des adversaires de caractère** — the Game over card with the record and rating
7. **À deux, sur un seul téléphone** — two of us, the board turned to Player 2
8. **Bois sculpté, vraies graines** — the store with Benin bronze on the board
